# Projeto Formulário de Inscrição

## Objetivo

Este projeto é um formulário simples de inscrição que captura informações básicas de um candidato, como nome, email, número de WhatsApp, área de atuação, observações e se deseja receber notificações por e-mail.

## Funcionalidades

1. **Campo de Nome:** Solicita o nome completo do candidato.
2. **Campo de Email:** Solicita o email do candidato.
3. **Campo de WhatsApp:** Solicita o número de WhatsApp do candidato.
4. **Grupo de Radio Buttons:** Permite que o candidato selecione sua área de atuação entre Desenvolvimento, Quality Assurance (QA), Análise de Dados, e Infraestrutura.
5. **Campo de Texto Longo:** Permite ao candidato fornecer observações sobre si mesmo.
6. **Checkbox:** Permite ao candidato confirmar se deseja receber novidades e ofertas por e-mail.
7. **Botão de Envio:** Permite ao candidato enviar suas informações.

## Tecnologias utilizadas

- HTML: Para o desenvolvimento da estrutura do formulário.
- CSS: Para estilizar o formulário (pode ser omitido se não houver estilos específicos).

## Como executar

1. **Baixe o arquivo:** Clique no botão "Ver mais" para baixar o arquivo `index.html`.
2. **Abra o arquivo:** Utilize um navegador web para abrir o arquivo `index.html` em sua máquina local.
3. **Complete o formulário:** Preencha todos os campos conforme solicitado.
4. **Envie o formulário:** Clique no botão "Enviar" para enviar suas informações.

## Conceitos de programação presentes

- **HTML:** Estruturação do formulário.
- **JavaScript:** (opcional) Para interações dinâmicas, se necessário.
- **CSS:** Estilo do formulário (opcional).
- **Responsive Design:** Adaptação do formulário para diferentes dispositivos.
- **Validação de Formulário:** Verificação de campos obrigatórios e tipo de dados.

Este projeto é um exemplo simples de um formulário de inscrição com funcionalidades básicas.
